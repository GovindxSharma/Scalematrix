STAGE 1 OF 3 Single Process Node

The Single Monolith: Architecture & Physical Breaking Points

All routing, domain logic, and database queries run inside a single JavaScript thread and process. Learn how it works, observe its physical single-core CPU ceiling, and see how to optimize it.

WHAT IT IS

A single deployable unit where all features share one memory space, one CPU event loop, and one database pool.

HOW IT WORKS

Direct in-memory function execution with 0.00ms network hop latency. Reads and writes execute directly against local data structures.

WHY IT BREAKS

A single CPU core reaches 100% capacity around 35,000 req/s, and synchronous SQL queries block the single thread.

HOW TO SCALE

Add in-memory caching (Redis/RAM) to bypass database queries for 85% of reads, then cluster across multiple CPU cores.

STAGE 2 OF 3 Domain Isolated + Multi-Core Cluster

The Modular Monolith: Multi-Core Clustering & Transaction Boundaries

Domains (Catalog, Orders, Inventory) are strictly isolated and clustered across multiple CPU cores (`cluster.fork()`). Learn how it handles scale and observe what happens when cross-domain database transactions collide.

WHAT IT IS

A single codebase with strict internal domain boundaries clustered across multiple physical CPU workers.

HOW IT WORKS

Domains communicate via an asynchronous in-memory event bus. Worker processes distribute HTTP requests across CPU cores.

WHY IT BREAKS

Synchronous inter-domain SQL transactions cause database lock queue saturation when traffic exceeds configured capacity.

HOW TO SCALE

Add asynchronous write-behind queues (BullMQ/Redis/Kafka) to turn database writes into non-blocking event batches.

STAGE 3 OF 3 Distributed Services + Network Mesh

Microservices: Network RPC Overhead & Distributed Concurrency

Each domain runs in an independent service container with its own database. Learn how services coordinate, measure cross-network latency tax, and see how horizontal autoscaling works.

WHAT IT IS

Independently deployed standalone services communicating over network protocols (HTTP/gRPC) behind an API Gateway.

HOW IT WORKS

Each service manages its dedicated database. Requests hop across network RPC layers with circuit breakers for fault isolation.

WHY IT BREAKS

Multiple synchronous HTTP REST hops add 20ms+ network serialization tax, and high load exhausts socket file descriptors.

HOW TO SCALE

Use gRPC HTTP/2 multiplexing, partition distributed lock keys (Redlock), and add horizontal container pods behind Anycast load balancers.

What Helps: Essential API Performance Patterns
  • Idempotency Keys (Idempotency-Key: uuid): Prevents double-charges during retries. Analogy: Like an elevator button — clicking floor 4 ten times still takes you to floor 4 once without charging 10 rides.
  • Conditional ETags (If-None-Match): Returns lightweight 304 Not Modified with 0-byte payload. Analogy: Asking "Anything changed?" and getting an instant "Nope" instead of re-reading a 500-page book.
  • Persistent HTTP Keep-Alive & Connection Pooling: Reuses TCP sockets, cutting 30-80ms lag. Analogy: Staying on an active phone call instead of hanging up and redialing before every sentence.
  • Cursor-Based Keyset Pagination (WHERE id > cursor): Eliminates slow full-table scans. Analogy: Putting a physical bookmark in a book instead of counting 100,000 pages from page 1 every time.
  • Circuit Breakers with Exponential Jitter: Isolates failing microservices. Analogy: Like a household electrical fuse that trips safely to protect your house when an appliance shorts out.
What Hurts: Hidden Obstacles & Production Bottlenecks
  • The N+1 Database Query Trap: Running 100 separate queries. Analogy: Driving to the grocery store 100 times to buy 1 item each trip, instead of buying all 100 items in 1 shopping cart.
  • Synchronous Chained REST Waterfalls: Chaining 4 synchronous microservice hops. Analogy: Passing a message down a 4-person chain where each person waits for the next before speaking.
  • Unbounded Responses (No Max Limit): Returning 50,000 JSON rows. Analogy: Asking a librarian for "some reading material" and having them dump 50,000 heavy encyclopedias on your lap.
  • Missing Socket & Request Timeouts: Hanging network sockets leak descriptors. Analogy: Leaving a garden hose running indefinitely until the water tank completely runs dry.
  • Synchronized Retries Without Jitter: Clients retry at the exact same millisecond. Analogy: 5,000 people rushing through a single store door at the exact same second after a blackout.
